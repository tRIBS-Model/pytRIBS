Examples
========

The following example workflows demonstrate pytRIBS end-to-end. For additional detail, see each
example's repository.

Newman Canyon, AZ, USA
----------------------

A comprehensive end-to-end workflow using pytRIBS to set up, execute, and analyze a TIN-based
Real-time Integrated Basin Simulator (tRIBS) distributed hydrologic modeling simulation of an
example watershed.

`pytRIBS Examples: Newman Canyon, AZ, USA <https://github.com/tRIBS-Model/pytRIBS-examples>`_

tRIBS Workshop Sandbox
----------------------

Developed for classes and workshops but usable by anyone, this example drives a tRIBS model with
observational data and demonstrates the calibration workflows. It is designed to run in a
`GitHub Codespace <https://docs.github.com/en/codespaces>`_, so the entire example can be executed
in a web browser with no local installation, but it can also be cloned and run locally.

`tRIBS Workshop Sandbox <https://github.com/tRIBS-Model/tRIBS-Workshop-Sandbox>`_
